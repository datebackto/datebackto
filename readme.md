# Gomoku Game

This repository now includes a simple console-based Gomoku (five-in-a-row) game that allows you to play against the computer.

## How to run

Run the following command:

```
python3 gomoku.py
```

Enter your moves as `row col` coordinates (0-indexed). Type `quit` to exit.

## Web interface

A minimal Flask-based web front end is provided in `web_gomoku.py`. Run it with:

```
python3 web_gomoku.py
```

Then open `http://localhost:5000` in your browser to play the game via a web page.
